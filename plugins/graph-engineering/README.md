# Graph Engineering Codex Plugin

This repository-owned Plugin is a thin MCP/Skill entry point. It requires `ge` 0.7.x on `PATH` and
an independently running project Runtime Service. The Plugin does not store Run state and does not
write SQLite, worktrees, or external handles.

For repository review, validate with the `plugin-creator` validator. Installation, publication, and
personal marketplace/config changes are intentionally not part of Phase 6A.
